# MY OS — prototype 0.1

Premier prototype mobile-first et hors ligne.

## Ce qui fonctionne
- Définir une seule priorité.
- Lancer une session de démarrage de 2 minutes.
- Ajouter, cocher et supprimer des tâches.
- Choisir ce qui bloque et recevoir une prochaine étape simple.
- Les données restent dans le stockage local du navigateur sur cet appareil.

## Tester
Ouvre `index.html` dans un navigateur pour un premier aperçu. Pour l'installation PWA et le mode hors ligne, le site doit être servi en HTTPS (par exemple GitHub Pages).

## Limites actuelles
- Pas encore de compte, de synchronisation, d'IA ou de notifications.
- Les données peuvent être perdues si les données du navigateur sont effacées.
- Le minuteur fonctionne tant que la page reste active.

## Prochaine étape
Tester le prototype sur téléphone, corriger les écrans avec tes retours, puis publier sur GitHub Pages. Ensuite, on pourra décider si une version Android native est réellement nécessaire.
